## Important before you launch

1. **Landing page check:** `/dashboard/services` may require login. Google Ads prefers a **public** page that anyone can open without signing in. If it redirects to login, use a public services/order page instead (or make that URL public).
2. **Policy:** Ads for social media “followers / likes / views” can be restricted. Use wording like **“promotion services”**, **“engagement growth”**, **“real users”** — avoid promising fake/bot traffic or guaranteed results.
3. **Conversion tracking:** Install Google tag / conversion tracking on foxigrow.com before scaling spend.
